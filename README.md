# evol-hive

A distributed evolutionary computation framework.

## Getting Started

### Prerequisites

- Python 3.9+
- Git

### Installation

```bash
git clone https://github.com/Redna/evol-hive.git
cd evol-hive
pip install -r requirements.txt
```

### Configuration

Copy the example environment file and configure your settings:

```bash
cp .env.example .env
# Edit .env with your settings
```

### Usage

```bash
python src/main.py
```
