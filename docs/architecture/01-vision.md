# §1 — Executive Vision & Core Philosophy

## Goal

Create a next-generation simulation environment where NPCs are fully autonomous, truly intelligent, and seamlessly integrated with deterministic game physics.

## Paradigm Shift

We move beyond:
- **Heavily scripted behavior trees** — rigid, predictable, limited
- **Prompt-chained AI architectures** (e.g., Stanford Generative Agents simulacra) — slow, expensive, rigid

Toward:
- **Real-time, fluid, computationally efficient embodied cognition** using local LLMs

## Core Insight

Instead of treating the AI as an external text generator that the game has to constantly parse and interpret, we treat the AI's cognitive functions (planning, remembering, reflecting) as **intrinsic tools within the game world itself**.

By using strict **Structured Outputs**, we bridge the chaotic, non-deterministic nature of LLM reasoning with the rigid, deterministic reality of a TypeScript physics engine.

## Result

A living, breathing sandbox where agents don't just "pretend" to live via text — they actively **perceive, plan, interact, and remember** within a mathematically sound physics simulation.
